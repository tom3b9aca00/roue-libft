# 🎡 Roue Libft

Une roue à tourner avec les 43 fonctions de la libft (42) pour s'entraîner :
tire une fonction au hasard et recode-la sans regarder.

- **Partie 1** (23) : fonctions de la libc (`ft_isalpha` … `ft_strdup`)
- **Partie 2** (11) : fonctions supplémentaires (`ft_substr` … `ft_putnbr_fd`)
- **Bonus** (9) : listes chaînées (`ft_lstnew` … `ft_lstmap`)

## Utilisation

Ouvre `index.html` dans un navigateur, ou active GitHub Pages
(Settings → Pages → branche `main`, dossier `/root`).

- Clique sur **Tourner !** (ou appuie sur Espace)
- Coche/décoche les parties à inclure
- « Retirer après tirage » pour ne jamais retomber sur la même fonction
