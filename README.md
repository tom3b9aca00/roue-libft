# 🎡 Roue Libft

Une roue à tourner avec les 43 fonctions de la libft (42)

- (23) : fonctions de la libc (`ft_isalpha` … `ft_strdup`)
- (11) : fonctions supplémentaires (`ft_substr` … `ft_putnbr_fd`)
- (9) : listes chaînées (`ft_lstnew` … `ft_lstmap`)

## Utilisation

Ouvre `index.html` dans un navigateur

- Clique sur **Tourner !** (ou appuie sur Espace)
- Coche/décoche les parties à inclure
- « Retirer après tirage » pour ne jamais retomber sur la même fonction
